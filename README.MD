# Video Report

Утилита CLI для выявления кликбейтных видео по метрикам из CSV-файлов.  
Кликбейтными считаются видео с `ctr > 15%` и `retention_rate < 40%`.  
Результат — таблица с заголовком, CTR и удержанием, отсортированная по убыванию CTR.

## Пример запуска
```
python main.py --files data/stats1.csv data/stats2.csv --report clickbait
```

## Архитектура
* reports/ — пакет с отчётами. Новый отчёт добавляется созданием класса, наследующего BaseReport, и регистрацией в reports/__init__.py.
* cli.py — разбор аргументов, чтение файлов, вывод через tabulate.
* utils.py — чтение CSV.
* tests/ - тесты (pytest) - покрывают фильтрацию, сортировку, обработку ошибок и CLI.
